# API Reference

Complete reference for all PM classes, modules, and methods.

## Classes and Modules

| Name | Description |
|------|-------------|
| [PM Module](pm-module.md) | Top-level module with all public class methods |
| [PM::Configuration](configuration.md) | Global settings: `prompts_dir`, `shell`, `erb`, `max_include_depth`, `strict_parameters`, locking |
| [PM::Metadata](metadata.md) | Hash-backed metadata container with dot notation |
| [PM::Parsed](parsed.md) | Result object from `PM.parse` |
| [PM::RenderContext](render-context.md) | Context passed to directive blocks |
| [Errors](errors.md) | The `PM::Error` hierarchy |
| [Constants](constants.md) | Regular expressions, markers, and key lists |
